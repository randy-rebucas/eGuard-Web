# eGuard Parent Marketing Video Production Kit

This package contains the production materials for the eGuard parent-focused marketing video.

## Files

### 01-Script
`eGuard_Parent_Marketing_Video_Script.md`
Complete voiceover, scene direction, timing, on-screen text, and production notes.

### 02-Resources
`eGuard_Video_Resource_List.csv`
Scene-by-scene resource inventory with source type, search prompts, resolution, and notes.

`Stock_Footage_Search_Pack.md`
Ready-to-use search terms for licensed stock footage libraries.

### 03-Asset-Checklist
`eGuard_Video_Asset_Checklist.md`
Production checklist for footage, UI, device mockups, branding, and distribution assets.

### 04-Reference
Contains the high-resolution eGuard visual reference board generated for the product direction.

## Recommended Master Format

- 3840 × 2160
- 16:9
- 24 or 30 fps
- H.264/H.265 final delivery
- Keep all UI source renders at 4K or higher

## Brand Direction

Premium + family-oriented + cinematic + professional + minimal + information-rich + light-blue accented + slightly futuristic.

The commercial should feel like a premium technology product advertisement, not a children's cartoon or surveillance product.
