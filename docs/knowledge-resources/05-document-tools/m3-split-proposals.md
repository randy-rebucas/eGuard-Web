# M3 split proposals

M3 split proposals lists, for each of the 26 eguard drafts checked on 2026-11-10, whether the draft covers more than one subject and, if it does, a proposed split in the M3 format: a title, category, suggested confidentiality and the sections each new document takes from the original. Sensitive material (costs, planned prices, competitor pricing, refund limits) goes into its own document so it can be protected separately. These are proposals only: no draft has been split, and each waits for the owner's approval.

## Company Glossary

No split needed. Every section defines terms for one subject, the shared eGuard vocabulary.

## Company Overview

No split needed. The document is a single company-level overview, and details already live in other documents.
