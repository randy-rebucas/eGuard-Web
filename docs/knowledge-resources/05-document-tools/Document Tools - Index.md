# Document tools

Results of the M prompts run on the eguard drafts. None of these files is uploaded to the Knowledge Library: they are working notes for the owner.

| # | Tool | How it is used in this run | Result file | Status |
|---|---|---|---|---|
| M1 | Interview me to build the fact sheet | Not used: the [fact sheet](../00-intro/project-fact-sheet.md) was filled from the sources. The owner's answers to its [TO CONFIRM] lines play the interview's role | – | Not needed |
| M2 | Turn raw material into a document | Not used as a separate step: every draft is written from the sources with its own C, P, D, S or T prompt | – | Not needed |
| M3 | Split a long document | Run on every draft. Splits are proposed, not made | [m3-split-proposals.md](m3-split-proposals.md) | Done: 8 proposals |
| M4 | Prepare a new version | Used later, when a published document changes (for example after the owner's answers or a price change) | – | Later |
| M5 | Contradiction check before upload | Run across all drafts: the same fact must have the same value and wording everywhere. Contradictions that come from the sources are listed, not resolved | [m5-contradiction-check.md](m5-contradiction-check.md) | Done: 24 fixes; 32 source contradictions listed |
| M6 | Find what knowledge is missing | Optional: needs a description of the AI employees, which the fact sheet does not have yet | – | Waits for owner's answers |
| M7 | Final check before upload | Run on each draft, ignoring the expected [TO CONFIRM] markers and Open questions sections. Problems fixable from the sources were fixed in the draft; the rest are listed | [m7-final-checks.md](m7-final-checks.md) | Done: 137 fixes |

The findings from these files are summarised in the [review report](../_review/Review%20-%20Index.md) at hand-over (step 6).
