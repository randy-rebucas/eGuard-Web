# M2 Turn raw material into a document

**How to use:** start a new chat and paste, in order, the [house rules](../00-intro/house-rules.md), your [project fact sheet](../00-intro/project-fact-sheet.md), then the prompt below. Paste any existing material after the prompt.

## Prompt

```text
Using the house rules and fact sheet above, turn the material below (meeting
notes, emails, chat messages, an old document) into one clean knowledge
document. First list the subjects you find in the material and which document
from this list each belongs to: <paste the catalogue table or your own list>.
Wait for me to choose. Then write the chosen document from the material only.
Where the material disagrees with itself, do not pick a side: describe both
versions under Open questions.

<paste the material here>
```
