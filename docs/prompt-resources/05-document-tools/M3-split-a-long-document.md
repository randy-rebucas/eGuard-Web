# M3 Split a long document

**How to use:** start a new chat and paste the [house rules](../00-intro/house-rules.md), then the prompt below, filling in the `<paste>` placeholders.

## Prompt

```text
Using the house rules above, the document below covers too many subjects for
search to work well. Propose a split into focused documents: for each, a title,
the category (Policy, SOP, Training, Technical, Financial, Legal, HR, Sales &
marketing, Customer support, Project, Reference), a suggested confidentiality
(Public, Internal, Confidential, Restricted), and which parts of the original go
into it. Put anything sensitive (prices, margins, personal data, contract terms)
in its own document so it can be protected separately. Wait for my approval,
then write the documents one at a time.

<paste the document here>
```
