# M4 Prepare a new version

**How to use:** start a new chat and paste the [house rules](../00-intro/house-rules.md), then the prompt below, filling in the `<paste>` placeholders.

## Prompt

```text
Using the house rules above, here is the current published version of a document
and the changes I need. Produce the full updated document (not just the changed
parts), keeping the same title, section titles and wording wherever nothing
changed, so the update is easy to review. Increase the version in Document
control and set the new effective date. Then, after the document, give a
"Change summary" list: section, what changed, why. I will put the change summary
in the upload description, not in the document.

Current version:
<paste>

Changes:
<describe>
```

## After drafting

Upload the result with **Upload new version** on the existing document, never as a new document.
