# M6 Find what knowledge is missing

**How to use:** paste the prompt below into a new chat and fill in the `<paste>` placeholders.

## Prompt

```text
Below is a description of my AI employees (role, department, what they do) and
the work I will give them on this project, plus the titles of the documents
already in my knowledge library. For each AI employee, list the questions it will
need answered to do this work well, and mark each question as Answered (name the
document), Partly answered, or Not answered. Then propose the missing documents,
using names from this catalogue where one fits: <paste the catalogue table>.
Order them by how much work would be blocked without them.

AI employees and work:
<describe>

Documents already published:
<list titles>
```
