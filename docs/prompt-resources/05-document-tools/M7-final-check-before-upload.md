# M7 Final check before upload

**How to use:** start a new chat and paste the [house rules](../00-intro/house-rules.md), then the prompt below, filling in the `<paste>` placeholders.

## Prompt

```text
Check the document below against the house rules above and list every problem:
any [TO CONFIRM] marker or Open questions section still present; sections that
do not make sense on their own; vague pronouns at the start of a section; facts
stated twice; inconsistent spelling of names or terms; missing units, currency
or time zones; anything addressed to an AI or phrased as an instruction to
software; passwords, keys, tokens, bank details or private personal data; and
more than one subject. Quote each problem and suggest the fix. Do not rewrite
the document.

<paste the document here>
```
