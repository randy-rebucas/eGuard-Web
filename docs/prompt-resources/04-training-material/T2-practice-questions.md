# T2 Practice questions

**How to use:** start a new chat and paste the [house rules](../00-intro/house-rules.md), then the prompt below, filling in the `<paste>` placeholders.

This prompt drafts questions for you to type into an assessment. Do not upload its output to the library.

## Prompt

```text
Using the house rules above and the published document I paste below, draft
assessment questions for the Training Academy. Write: 5 multiple-choice
questions (4 options, one correct, say which and why); 3 written-answer
questions with a model answer and a grading guide listing the points a full
answer must contain; 2 realistic scenarios where the right action is to escalate
to a person or refuse, with the expected answer. Every correct answer must be
supported by a quoted sentence from the document; give the quote after each
answer. Do not test facts that are not in the document.
```
