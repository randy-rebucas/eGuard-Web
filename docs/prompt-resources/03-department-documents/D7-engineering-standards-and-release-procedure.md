# D7 Engineering standards and release procedure

| Category | Confidentiality | Available to |
|---|---|---|
| SOP (controlled) | Internal | Department: engineering |

**How to use:** start a new chat and paste, in order, the [house rules](../00-intro/house-rules.md), your [project fact sheet](../00-intro/project-fact-sheet.md), then the prompt below. Paste any existing material after the prompt.

## Prompt

```text
Using the house rules and fact sheet above, write the SOP "Engineering Standards
and Release Procedure". Sections: Summary; Code style and review rules; Branches
and pull requests (naming, who reviews, what must pass); Testing expectations;
Release steps (numbered); Rollback steps (numbered); Change approvals (what needs
approval and from which role); Incident hand-over; Document control; Open
questions.
```
