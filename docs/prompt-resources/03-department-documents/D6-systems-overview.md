# D6 Systems overview

| Category | Confidentiality | Available to |
|---|---|---|
| Technical | Internal | Department: engineering |

**How to use:** start a new chat and paste, in order, the [house rules](../00-intro/house-rules.md), your [project fact sheet](../00-intro/project-fact-sheet.md), then the prompt below. Paste any existing material after the prompt.

## Prompt

```text
Using the house rules and fact sheet above, write "Systems Overview" for the
engineering team. Sections: Summary; Systems we use (one "## " section per
system: purpose, who owns it, what data it holds, which other systems it talks
to, where its documentation lives); How data flows between systems (numbered
description); Environments (development, test, production) and how changes move
between them; Monitoring and who is alerted; Known limitations; Document control;
Open questions. Never include hostnames that are secret, passwords, keys or
connection strings.
```
