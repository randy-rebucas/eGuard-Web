# S1 Any procedure (generic SOP)

| Category | Confidentiality | Available to |
|---|---|---|
| SOP (controlled) | Internal | The department or role that runs it |

**How to use:** start a new chat and paste, in order, the [house rules](../00-intro/house-rules.md), your [project fact sheet](../00-intro/project-fact-sheet.md), then the prompt below. Paste any existing material after the prompt.

## Prompt

```text
Using the house rules and fact sheet above, write the SOP "<Procedure name>".
Sections: Summary; Purpose; When this procedure applies (and when it does not);
Roles involved (role: responsibility); Inputs needed before starting;
Procedure (numbered steps; each step names the role that does it and the system
used; mark decision points as "If ... then go to step N"); Approvals required
(what, who, limit); Exceptions and what to do; Outputs and where they are
recorded; Time targets; Document control; Open questions.
```
