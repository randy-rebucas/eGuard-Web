# P4 Decision log

| Category | Confidentiality | Available to |
|---|---|---|
| Project | Internal | Project (objective) |

**How to use:** start a new chat and paste, in order, the [house rules](../00-intro/house-rules.md), your [project fact sheet](../00-intro/project-fact-sheet.md), then the prompt below. Paste any existing material after the prompt.

## Prompt

```text
Using the house rules and fact sheet above, write "<Project name>: Decision Log"
from the decisions in my fact sheet and material. One "## " section per
decision, titled "<Project name> decision D<number>: <short title>". In each:
date; decided by (role); the decision in one sentence; reasons; options
rejected and why; what it affects; status (in force / replaced by D<n>).
Never record a decision that my material does not clearly state as made; list
undecided questions under Open questions. Then Document control.
```

## After drafting

When a decision changes, upload a new version of this document (**Upload new version**), never a second decision log.
