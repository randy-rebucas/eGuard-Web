# P2 Requirements and acceptance criteria

| Category | Confidentiality | Available to |
|---|---|---|
| Project | Internal | Project (objective) |

**How to use:** start a new chat and paste, in order, the [house rules](../00-intro/house-rules.md), your [project fact sheet](../00-intro/project-fact-sheet.md), then the prompt below. Paste any existing material after the prompt.

## Prompt

```text
Using the house rules and fact sheet above, write "<Project name>: Requirements
and Acceptance Criteria". Number each requirement (R1, R2, ...). Group them in
"## " sections by area. For each requirement give: the requirement in one
sentence; why it matters; priority (Must / Should / Could); acceptance criteria
as a numbered list of checks someone could verify with a yes or no.
Add a section "<Project name>: Definition of done" for the project as a whole.
Do not add requirements that are not in my material; list likely missing ones
under Open questions instead. Then Document control and Open questions.
```
