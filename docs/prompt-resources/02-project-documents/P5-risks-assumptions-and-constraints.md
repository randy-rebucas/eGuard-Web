# P5 Risks, assumptions and constraints

| Category | Confidentiality | Available to |
|---|---|---|
| Project | Internal | Project (objective) |

**How to use:** start a new chat and paste, in order, the [house rules](../00-intro/house-rules.md), your [project fact sheet](../00-intro/project-fact-sheet.md), then the prompt below. Paste any existing material after the prompt.

## Prompt

```text
Using the house rules and fact sheet above, write "<Project name>: Risks,
Assumptions and Constraints". Sections: Summary; Risks (table: ID | Risk |
Likelihood (Low/Medium/High) | Impact (Low/Medium/High) | Mitigation | Owner role
| Trigger that means it is happening); Assumptions (table: ID | Assumption | How
we will check it | By when); Constraints (table: Constraint | Source |
Consequence if broken); Document control; Open questions.
You may suggest additional risks, but put them only under Open questions,
marked "Suggested, not confirmed".
```
