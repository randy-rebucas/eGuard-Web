# P1 Project brief

| Category | Confidentiality | Available to |
|---|---|---|
| Project | Internal | Project (objective) |

**How to use:** start a new chat and paste, in order, the [house rules](../00-intro/house-rules.md), your [project fact sheet](../00-intro/project-fact-sheet.md), then the prompt below. Paste any existing material after the prompt.

## Prompt

```text
Using the house rules and fact sheet above, write "<Project name>: Project Brief".
Sections: Summary (goal, deadline, main deliverable in 3-5 sentences);
Background and business problem; Goal and success measures (measurable, with
targets); Scope: included; Scope: excluded; Deliverables (table: Deliverable |
Description | Due date | Owner role); Timeline and milestones (table);
Budget and cost limits; Teams and roles involved; Constraints;
Related documents; Document control; Open questions.
Start every section title with the project name, for example
"## <Project name>: Scope included".
```
